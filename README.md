# Proyecto Final - Informática 2

## Videojuego

Gumball: Viaje temporal por el Metro de Medellín

## Descripción

Videojuego 2D desarrollado en C++ utilizando programación
orientada a objetos, memoria dinámica y Qt.

El jugador controla a Gumball, quien viaja accidentalmente
al pasado y debe recorrer dos escenarios relacionados con
la construcción y puesta en funcionamiento del Metro de Medellín.

## Niveles

### Nivel 1
Construcción del Metro de Medellín.

### Nivel 2
Primer recorrido del Metro de Medellín.

## Controles

- Flecha izquierda: mover a la izquierda.
- Flecha derecha: mover a la derecha.
- Espacio: saltar.
- P: pausar.

## Tecnologías

- C++
- Qt
- Qt Creator
- Programación orientada a objetos
- Memoria dinámica
